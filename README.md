
Sistema de Gestión de Pacientes - Laravel SPA

Esta plataforma está desarrollada con Laravel y permite consultar, dar de alta y modificar pacientes de un hospital.
Todas las operaciones se realizan en una única página, recargando los componentes de forma dinámica, cumpliendo así con el modelo de diseño SPA (Single Page Application).

Además, el sistema incorpora paginación en la consulta de pacientes, implementada mediante el middleware de Laravel para optimizar la carga y la gestión de datos.

✨ Características principales

CRUD completo de pacientes (alta, consulta, edición y eliminación).

Arquitectura SPA con recarga dinámica de componentes.

La base de dato se encuentra en la raiz del proyecto en una carpeta bbdd  en un archivo .sql
